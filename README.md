# Nest.js Backend of ai dream chatbot

Бэкенд разработан на NestJS с использованием Prisma ORM и PostgreSQL. Он предоставляет REST API для работы с пользователями, снами и аутентификацией.

✅ Основные модули API:
1. Пользователи (Users)
POST /users — создание нового пользователя
GET /users — получение списка всех пользователей (админ)
GET /users/{id} — получение информации о конкретном пользователе
PATCH /users/{id} — обновление данных пользователя
DELETE /users/{id} — удаление пользователя (админ)
Используется для регистрации, профиля и управления аккаунтами. 

2. Сны (Dreams)
POST /dreams — сохранение нового сна (требует авторизации)
GET /dreams — получение истории снов текущего пользователя
POST /dreams/interpret-public — публичный анализ сна (без авторизации)
POST /dreams/interpret — приватный анализ сна (только для авторизованных)
Обрабатывает отправку сна и возвращает интерпретацию от LLM (OpenAI). 

3. Аутентификация и авторизация (Auth)
POST /auth/register — регистрация нового пользователя
POST /auth/login — вход (возвращает JWT-токен)
POST /auth/logout — выход (инвалидация токена)
GET /auth/me — получение данных текущего пользователя по токену
Реализована защита роутов через JWT. Только зарегистрированные пользователи могут отправлять сны и просматривать историю. 

🔐 Безопасность и архитектура
Все эндпоинты, кроме /dreams/interpret-public, требуют валидного JWT-токена.
Используется CORS для ограничения доступа только с фронтенда (например, http://localhost:5173).
Данные хранятся в PostgreSQL — надёжная и масштабируемая БД.
Логика анализа сна вынесена в сервисы — готова к интеграции с LLM (OpenAI, YandexGPT и др.).
🚀 Готов к интеграции с Telegram-ботом
Бэкенд может работать как REST API для внешних клиентов (включая Telegram-бота), предоставляя:

Авторизацию
Сохранение снов
Анализ сна (публичный и приватный)
Получение истории и статистики

## Run 
`npm run start`
