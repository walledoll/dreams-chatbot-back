# 🌙 СоннИИк API — Бэкенд

REST API для сервиса анализа снов на базе **NestJS**, **Prisma** и **PostgreSQL**.

---

### 🚀 Возможности

- 🔐 **Аутентификация** через JWT
- 👤 **Управление пользователями**: регистрация, вход, профиль
- 💤 **Работа со снами**: сохранение, анализ (публичный/приватный), история
- 📊 **Статистика по эмоциям**
- 🤖 **Интеграция с LLM** (через OpenAI API proxy)
- 📦 **Готов к масштабированию**: модульная архитектура, типобезопасность

---

### 🛠 Технологии

- **NestJS** — фреймворк для сервера
- **Prisma ORM** — работа с БД
- **PostgreSQL** — основная база данных
- **JWT** — безопасная аутентификация
- **Swagger** — документация API (`/api`)
- **CORS** — защита от неавторизованных источников

---

### 📡 Эндпоинты

#### Аутентификация
- `POST /auth/register` — регистрация
- `POST /auth/login` — вход
- `GET /auth/me` — получить профиль

#### Пользователи
- `GET /users` — список (админ)
- `GET /users/:id` — профиль
- `PATCH /users/:id` — обновление
- `DELETE /users/:id` — удаление (админ)

#### Сны
- `POST /dreams/interpret-public` — публичный анализ (без входа)
- `POST /dreams/interpret` — приватный анализ (требует JWT)
- `GET /dreams` — история снов пользователя
- `POST /dreams` — сохранение сна

### ⚙️ Локальный запуск

```bash
# 1. Установите зависимости
npm install

# 2. Настройте .env
touch .env
# Укажите DATABASE_URL и JWT_SECRET

# 3. Примените миграции
npx prisma migrate dev

# 4. Запустите сервер
npm run start:dev  # http://localhost:3000
```

> 💡 Документация API: `http://localhost:3000/api`
